 FixItNow – Django Municipal Issue Reporting System

Overview
FixItNow is a Django-based municipal issue reporting and tracking system developed as part of a Human-Computer Interaction (HCI) project.

The system allows users to report municipal service delivery problems such as:
- Water leaks
- Electricity faults
- Road damage
- Sanitation issues

Users can also track the progress of their submitted reports through different status stages.

 Features
- User registration and login
- Report municipal issues
- Add issue descriptions
- Upload supporting images
- Track issue progress
- Dashboard overview
- Edit and manage reports

 Technologies Used
- Django
- Python
- HTML
- CSS
- SQLite


System Functionality
The system was designed to help improve communication between citizens and municipalities by providing a centralized platform for reporting and tracking service delivery issues.

Main system modules include:
- Authentication system
- Dashboard
- Issue reporting form
- Issue tracking page
- Status management
